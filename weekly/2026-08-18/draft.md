## 1.〔社会〕使っているのは半数、不安は上がっている

**何が起きたか。** Gallupの継続調査の数字が出そろった。米国の労働者について。

| | |
|---|---|
| 勤務先がAIを導入した | **47%**（前四半期41%から**6ポイント**上昇） |
| 業務でAIを使っている | **52%**（週数回以上30%、毎日15%） |
| 職場が「大きく破壊的に変化した」 | AI導入組織の従業員の**27%** |
| 5年以内に自分の仕事が無くなると思う | **18%**（AI実装済みの組織では**23%**） |
| 今後10年でAIは米国の雇用を減らす | **79%**（2025年の73%から上昇） |

**この5行の並びが、そのまま構造を語っている。** 導入率も利用率も上がっているのに、
不安は下がらず、むしろ**AIが入っている職場のほうが「消えるかも」と答える人が多い**（18%→23%）。
「使えば安心する」という前提は、データの上では成り立っていない。

`⟨おざけんの見立て⟩`

**外れる条件**：利用率がさらに上がった先で不安の数字が下がり始めたら、この読みは外れ。

## 2.〔組織〕日本企業の活用は、二極化している

**何が起きたか。** JIPDEC『企業IT利活用動向調査2026』のAI活用編。
**事業レベルでAIを活用できている企業は36%。** 発表の見出しは
「AI活用成熟度は二極化、入出力データに関する課題感は導入後も継続」。

業種差が大きい。情報通信・金融保険は積極活用、公共その他は**半数以上が検討段階**。
そして**DXの実践段階が進んでいる企業ほど、AI活用も深い**という相関が出ている。

**仕組みとして読むなら、AIの成否がAIの前段で決まっているということ。**
中小機構の調査でも、費用助成と並んで「活用事例などの情報提供」が高いニーズに挙がっている。
足りないのはツールでも予算でもなく、**手本**だと現場が言っている。

`⟨おざけんの見立て⟩`

**外れる条件**：翌年の同調査で二極化が縮まっていたら、この読みは弱まる。

> 関連：`05_drive/five-walls.html` / `05_drive/kiban-phase.html`
> **注意**：36%の「事業レベル」の定義（試用・PoC・本番のどこからか）は原典で要確認。

## 3.〔人材〕余る職と、足りない職が、同時に増える

**何が起きたか。** 経産省『2040年の就業構造推計（改訂版）』（2026年3月）。

| 不足しうる | | 余剰になりうる | |
|---|---|---|---|
| AI・ロボット等利活用人材 | **約340万人** | 事務職 | **約440万人** |
| 現場人材 | 約260万人 | 文系人材 | 約80万人 |
| 理系人材 | 約120万人 | | |

就業者数は約6,700万人（2022年）から約6,300万人へ。
ただし推計は、**十分な国内投資と産業構造転換が実現すれば、
AI・ロボット利活用とリスキリングで労働需要が効率化され、全体では大きな不足は生じない**としている。

**「人手不足だからAI」ではなく、「AIを入れた先で、余る職と足りない職が同時に立つ」** という絵である。
440万と340万は、足し引きできる数字ではない。**別の人たちの話**だからだ。

`⟨おざけんの見立て⟩`

**外れる条件**：余剰とされた職種で求人が減らなければ、この推計の読み方は外れ。

> 関連：`06_people/career-in-agent-era.html` / `06_people/jinji-seido.html`

## 4.〔技術〕エージェントの失敗は、賢さではなく「持続」の設計で起きている

**何が起きたか。** 8月7日、サーベイ論文 `The Horizon Gap` が公開。
2024〜2026年のarXiv論文**1,547本**を読み込み、長時間タスクで何が壊れるかを整理したもの。

**芯は、3つの言葉を切り分けたこと。**

| 言葉 | 何の性質か | 中身 |
|---|---|---|
| long-horizon | **タスク**の性質 | 完了までに必要な手数 |
| long-context | **モデル**の性質 | 一度に読めるトークンの量 |
| long-term memory | **システム**の性質 | セッションを跨いで残るか |

現場ではこの3つが混ざる。「コンテキストを広げれば長い仕事を任せられる」という誤解は、
1番目と2番目を同じものだと思うところから来ている。**手数の多さは、窓の広さでは解けない。**

同じ方向の実験がもう1つ。Emergence World はLLMエージェントの集団を走らせ続ける評価基盤で、
**15日間・5つの並列世界**で回した結果が、「安定した合議的な統治」から「集団の崩壊」まで**割れた**。
数分で終わるベンチマークの点数と、週単位で走らせたときの信頼性は別物だという話である。

`⟨おざけんの見立て⟩`

**外れる条件**：長時間タスクの失敗が、設計ではなくモデルの賢さの向上だけで消えていったら外れ。

> 関連：`01_concept/human-in-on-the-loop-v2.html` / `04_practice/build-a-workflow.html`

## 5.〔技術〕賢さの差は3ポイント、値段の差は2倍 ── そして12月31日に価格が変わる

**何が起きたか。** 8月13日、Gemini 3.7 Flash がGA。

| | 入力（100万トークン） | 出力（100万トークン） |
|---|---|---|
| **導入価格（〜2026/12/31）** | $0.75 | $3.75 |
| **標準価格（2027/1/1〜）** | $1.50 | $7.50 |

コンテキスト100万トークン、最大出力64k、thinkingは low / medium / high の3段。
同じ週に Grok 4.6（8/12・$2.00／$6.00）、前週に Muse Spark 1.2（8/5・$1.25／$4.25）。

**Artificial Analysis の計測（8/18確認）では、Gemini 3.7 Flash (high) が Intelligence Index 56。**
GPT-5.6 Terra (max) 57、Muse Spark 1.2 (xhigh) 57 のすぐ下で、
出力速度は**約340トークン/秒** ── Terra や GLM-5.2 の約3倍。

**効くのは賢さより2つの数字。** 1つは**速度**。エージェントは往復が多いので、
1回の速さがそのまま待ち時間になる。もう1つは**切替日**。
導入価格で試算して通した予算は、**1月1日に倍額**になる。

`⟨おざけんの見立て⟩`

**外れる条件**：導入価格が延長されるか標準価格が下がれば、期ずれの警告は不要になる。

> 関連：`02_models/model-selection.html` / `05_drive/ai-budget.html`

## 6.〔産業〕お金は、上位2社に集まっている

**何が起きたか。** Crunchbaseの集計で、2026年上半期の世界のベンチャー投資は**過去最高の$510B**。
2025年**通年**の$440Bを、**半年**で超えた。四半期別ではQ1 $305B、Q2 $205B（5,000社超）。

そして、**OpenAI と Anthropic の2社だけで $217B ── 上半期全体の43%**。

**スタートアップ投資の話をしているのに、半分近くが2社の話になっている。**
「AIに金が集まっている」ではなく、「AIの中でも2社に集まっている」が正確な形である。

`⟨おざけんの見立て⟩`

**外れる条件**：下半期に集中度が下がれば、この読みは弱まる。

> **検証メモ**：二次情報では「AIスタートアップがH1で$407B」「通年$120B超の見込み」という
> **桁の割れた数字が同時に出回っていた**。集計元（Crunchbase）に当たって上の数字に落ち着いた。
> なお、AI分野だけに限定した合計額は、今回は特定できていない（$510Bは全分野の数字）。

## 7.〔法規制／インフラ〕日本のAIデータセンターは、電気の「列」で詰まっている

**何が起きたか。** 経産省が、東京・関西・九州エリアで**系統接続の手続き中のデータセンター**を実態調査している。
手続きが進まない理由や、計画変更の有無を把握するため。

**仕組みとして押さえるべきは、接続キューが「早い者勝ち」だという点。**
いま需要家の申込行動を制限する手立てがなく、**実需のない過剰な申込が列を作ると、後続の接続が遅れる**。
過剰投資が積み上がれば、託送料金（送配電網の利用料）に跳ね返る懸念もある。
RIETIは、AI事業者に電源・送配電・バックアップの自前調達を求める案を論じている。

つまり日本のボトルネックは発電量そのものより、**手続きの列と、並ぶ権利の設計**にある。

`⟨おざけんの見立て⟩`

> **注意：この節は所在の確認まで。** 待ち年数などの数値は原典PDFを読めておらず、
> 一次資料に当たるまで数字を書かない。
