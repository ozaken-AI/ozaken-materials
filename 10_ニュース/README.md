# 10_ニュース ─ AIニュースの収集と反映

生成AI・AIエージェント・フィジカルAIのニュースを **週に1回集めて、月に1回束ね直す** ための置き場。

## 中身

| パス | 何が入っているか |
|---|---|
| `weekly/YYYY-Www.md` | 週次ダイジェスト（その週のニュース本体） |
| `weekly/YYYY-Www-反映提案.md` | 既存資料への反映提案と、その承認・却下の記録 |
| `monthly/YYYY-MM.md` | 月次トレンドの原稿（index.html に載せる元データ） |
| `トレンドアーカイブ.html` | 過去月のトレンドを積み上げた公開ページ |

最新月のトレンドは `index.html` の「今月のAIトレンド」セクションに出る。
それ以前の月は `トレンドアーカイブ.html` に降りていく。

## 流れ

```
毎週土曜 9:00 ─┐
              ├─ ニュース収集 → weekly/ にダイジェスト追加
              ├─ 既存資料への反映提案を作る（この時点では資料を変更しない）
              ├─ ブランチ + PR → Slack DM でおざけんに通知
              └─ おざけんがPRで承認した提案だけを反映 → おざけんがマージ

毎月1日 9:00 ─┐
              ├─ 前月の週次ダイジェストを束ねて monthly/ に原稿を作る
              ├─ index.html のトレンド枠を差し替え、先月ぶんをアーカイブへ送る
              └─ PR → Slack 通知 → おざけんがマージ
```

**既存資料の本文が、おざけんの承認なしに書き換わることはない。**
提案は必ずPRの形で出て、承認された番号だけが反映される。

## 動かしているもの

| 何 | どこ |
|---|---|
| 週次の手順 | `.claude/skills/ai-news-weekly/SKILL.md` |
| 月次の手順 | `.claude/skills/ai-news-monthly/SKILL.md` |
| 情報源と採否の基準 | `.claude/skills/ai-news-weekly/references/sources.md` |
| 資料↔トピックの対応表 | `.claude/skills/ai-news-weekly/references/material-map.md` |
| 暗号化資料の復号・再暗号化 | `.claude/skills/ai-news-weekly/scripts/archive_crypto.py` |

自動実行は Routine（定期トリガー）で動かしている。手動で回したいときは、
セッションで「今週のAIニュースをまとめて」（週次）／「今月のAIトレンドを更新して」（月次）と言えば同じ手順が走る。

| Routine | 実行 |
|---|---|
| 週次AIニュース収集 → 反映提案 | 毎週土曜 9:00 JST |
| 月次AIトレンド → index.html 反映 | 毎月1日 9:00 JST（前月分をまとめる） |

⚠️ Routine から起動したセッションに Slack / GitHub のツールが渡らないことがある。
その場合もブランチのpushまでは必ず完了し、PR作成URLと通知内容を最終出力に書いて、
プッシュ通知で届くようにしている。恒久的に直すには、claude.ai の Routine 設定画面から
Slack / GitHub のコネクタを紐づける（コマンドラインからは付与できない）。

## 資料を追加したら

`material-map.md` に1行足すこと。この表に載っていない資料には、週次ジョブは反映提案を出さない。

## 既存資料の暗号化について

`index.html` と `10_ニュース/` 以外のHTMLは、本文がAES-GCMで暗号化されている。
自動反映まで通すには、環境変数 `OZAKEN_ARCHIVE_PW` にアーカイブのパスワードが必要。

未設定でも週次ジョブは動く。その場合は**提案までを出して止まり**、
「パスワードが無いので反映は手元でお願いします」とPRとSlackに書く。
