# OZAKEN LETTER の戦略

このメールマガジンを、何のために、誰に、どう出すか。
**仕組みの話は [`newsletter-system.md`](./newsletter-system.md) に、ここには考え方を書く。**

作成 2026年8月28日 ／ 名簿1,131件・まだ1通も出していない時点。

---

## 1. 何のためにあるのか

**受注のためではない。「思い出される状態」を作るため。**

おざけんの仕事は、年間300回以上の登壇にせよ顧問にせよ、**探されて選ばれて**いる。
こちらから追いかけて取っているわけではない。営業チームも無い。

ということは、必要なのはリードを集めることではなく、
**社内でAIの議論が起きたその瞬間に、名前が挙がること**。

> 「うちもエージェント、そろそろ考えないとね」
> 「あの、5レベルの資料の人に聞いてみますか」

この2行目が出るかどうか。それだけを狙う。

だから、よくあるBtoBのナーチャリング（スコアリング → MQL → インサイドセールスが架電）
とは設計が根本的に違う。**追いかける人がいないので、追いかける仕組みを作っても回らない。**
代わりに、**向こうから手が挙がる**構えを作る。

その唯一の証拠が **返信** になる。開封率でもクリック率でもない。

---

## 2. いま名簿にいるのは誰か

推測ではなく、実測。1,131件の内訳。

| | |
|---|---|
| どこから来たか | **89%が「使うAIから任せるAIへ／AIエージェント実装の5レベル」1本** |
| 誰か | **独自ドメイン 930件（82%）／722社** |
| どう扱われているか | **116社では複数人が同じ資料を落としている**（324件） |
| いつ | 2026-07-29〜08-28 の30日。直近7日は53件（4%）で、初動の山は越えた |

ここから3つ言える。

**① 単一テーマの名簿である。**
89%が同じ1本から来ている。関心の方向がはっきりしているので、
別の話題を送ると「頼んでいない」になる。逆に、その延長線上なら深く刺さる。

**② 個人ではなく、組織の中の人。**
82%が法人ドメイン。学びたい個人ではなく、**組織で動かす立場**の実務者。
書き方も、届ける内容も、そこに合わせる。

**③ すでに社内で回覧されている。**
116社で複数人が落としている。これは「一人が興味を持った」のではなく、
**検討が始まっている**ということ。ここが一番大きい発見。

## 3. 読者はどこで止まっているか

**関心はある。動き出す手前で止まっている。**

「AIエージェント実装の5レベル」を落とす人は、
エージェントという言葉を知らないわけではない。順番が分からないのでもない
（資料に書いてある）。それでも動いていないから、資料を探している。

止まる理由は、おざけん自身が現場で見てきたものと同じ。

- 完璧な計画を待っている
- 体制・ルール・費用対効果を先に固めようとしている
- 技術力の問題だと思っている

**だからこのメールマガジンの仕事は、関心を作ることではない。
止まっている理由を外して、最初の一歩を手渡すことになる。**

これは既に言葉になっている。

> AI活用が進むかどうかは、技術力では決まりません。
> 完璧な計画を待たずに、80点で動かして、現場で磨く。

**この一文を、毎号ちがう角度から証明し続ける。** それがこのメルマガの背骨になる。

---

## 4. ナーチャリングの設計

段階を3つに切る。**同時に全部やらない。**

### 段階① 思い出してもらう（1〜2通目）

大半が3〜4週間前の接触。**まず「誰から届いたか」を確定させる。**

- なぜ届いているのか（資料をダウンロードいただいた経緯）を冒頭に置く
- 資料の**続き**を渡す ＝ 受け取った側から見れば、約束が果たされたことになる
- ここで数十人が抜ける。**それが正常で、狙い**

### 段階② 見方を渡す（3通目以降・定常）

**ここがナーチャリングの本体。**

「前提が変わった論点」を、なぜ変わったのかまで書いて送る。
これを続けると、読者の中でこうなる。

> AIの動きを、おざけんの見方で見るようになる。

商品を売り込んで検討させるのではなく、**ものの見方を渡して、
判断の枠組みごと共有してもらう。** 枠組みを共有した相手は、
判断が必要になったときに、その枠組みをくれた人に聞く。

### 段階③ 手を挙げてもらう（常時＋年に数回）

- **常時**：毎号、返信を誘う。「一行でも構いません」
- **常時**：全文ページの合言葉を購読者だけに渡す（特別扱いの実感）
- **年に数回だけ**：明示的な入口（少人数の会、無料相談、研修の案内）

**③の「明示的な入口」を毎号やらないことが肝。**
営業を混ぜた瞬間に②の価値が落ちる。年に2〜3回でいい。

## 5. 号の型と、3本を選ぶ基準

型は決まっている（要点3本＋全文は資料アーカイブへ）。
戦略として決めるべきは **何を3本に選ぶか**。

**3つとも満たすものだけ選ぶ。**

1. **前提が変わったか。** 新しいだけのものは選ばない。
   「これまでこう考えられていたが、そうではなくなった」と言えるか
2. **現場に降りてきているか。** 研究成果・ベンチマークは、
   実際に業務に置かれるまで書かない。**これが「最先端ではなく最前線」の運用上の定義**
3. **読者が明日動けるか。** 読んで「へえ」で終わるものは、1本も要らない

この3つで落とすと、書けるネタは激減する。**それでいい。**
月1〜3通と約束してあるのは、そのためでもある。

---

## 6. ネタはどこから来るか

**素材は枯れない。年間300回の登壇と1,500本の執筆がある。** 問題は書く時間なので、
供給源を決めておく。

| 供給源 | 何が取れるか |
|---|---|
| `weekly/threads/*.json` | 定点観測。前提が動いた瞬間が拾える |
| **`ask.html` に溜まる質問** | **会場で出た質問は、名簿の1,131人も同じことを思っている** |
| 登壇の現場で聞いた話 | 事例。ここが他の誰にも書けない部分 |
| 資料アーカイブ105本 | 深掘りの受け皿。号では要点、詳しくはアーカイブへ |

**ask.html の質問を号のネタにする循環が、いちばん効く。**
会場で1人が聞いたということは、聞けなかった人が何十人もいる。
その質問に答える号は、必ず刺さる。

## 7. 測るもの、測らないもの

### 主指標：返信数

**号あたり何件返ってきたか。** これだけを追う。

返信は「関係が始まった証拠」であり、そのまま**相談の芽**でもある。
1,131人に送って3件返ってくれば、それは3件の見込み客ではなく、
**3件の会話**。おざけんの商売はそこから始まる。

### 監視する数字（越えたら止める）

| | 線 | 越えたら |
|---|---|---|
| 迷惑メール報告率 | **0.1%** で警戒、**0.3%** で Gmail に届かなくなる | 送る相手か文面を疑う |
| バウンス率 | **2%** | 名簿の質を疑う |
| 配信停止 | 号あたり1%を大きく超えたら | 内容が期待と違っている |

管理画面の「概況」で、直近7日の動きが見える。
**苦情率が 0.3% を超えた号は、号の一覧で赤く出る。**

### 測らないもの

- **開封率。** Apple のメールプライバシー保護で、数字が意味を持たない
- **スコアリング。** 追いかける人がいないので、点数を付けても使い道がない

## 8. やらないこと

戦略は、やらないことで決まる。

| やらない | なぜ |
|---|---|
| **ステップメール（自動シナリオ）** | 「不定期」と矛盾する。作る手間も回収できない |
| **セグメント配信**（当面） | 1,131件を割ると各群が小さすぎて、何も学べない。まず全員に送って反応を見る |
| **頻度を上げる** | 月1〜3通と約束した。守れないなら約束しないほうがいい |
| **リードスコアリング** | 追いかける人がいない |
| **開封率の改善** | 測れない数字は改善できない |
| **他社の宣伝・広告** | 一度でも入れると、読む理由が変わる |

## 9. 最初の3通

### 1通目：ご挨拶号 ── ただし挨拶だけにしない

1,131人は誰も、まだ1通も受け取っていない。**通常号として出さない。**

1. なぜ届いているか（資料をダウンロードいただいた経緯）
2. **「5レベル」の続きを1本** ← これが本体。挨拶だけの号にしない
3. 今後お送りするもの
4. 不要ならここで止められること

**中身の案：「5レベルのうち、現場が実際に詰まるのはレベル2→3」。**
89%がその資料を読んでいるので、続きとして完璧に接続する。
しかも「止まっている理由を外す」という、このメルマガの背骨そのものになる。

段階配信で4日に分ける（75 / 151 / 302 / 603）。

### 2通目：1通目への返信から作る

**1通目で返ってきた質問に答える号にする。**
「同じことを思った方が多かったので」と書けると、
読者は「自分の問いが届く相手だ」と分かる。**返信の量はここで決まる。**

### 3通目：定常運転へ

前提が変わった論点を3本。以後この型。

## 10. いつ見直すか

**3号出したところで、一度立ち止まる。**

見るのは3つだけ。

1. **返信は来たか。** 0件なら、返信の誘い方か、内容の当事者性が足りていない
2. **配信停止の出方。** 1通目で数十人抜けるのは正常。3通目でも同じ率なら、期待と中身がずれている
3. **名簿は増えているか。** 資料ダウンロードとトップページの登録欄からの純増

**増えていないなら、それは配信の問題ではなく入口の問題。**
そのときは講演のQRから購読への導線（未着手）を作る。
