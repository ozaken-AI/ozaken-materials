# 講演・印刷のデザイン規約

2026年9月の本人指定を、次に資料を作るAIにも引き継ぐための規約です。
対象はテンプレート便覧、新しく作る講演資料、講演用として改訂する資料。
既存の全資料を自動的に移行する指示ではありません。研修で明示的に依頼された演習・ワークシートは用途を分けて設計します。

## 読むための操作を要求しない

- 比較の両側、工程の全段階、問いと答え、根拠・注釈は同じ面で読めるようにする。
- 「この章の解説」「元の図を読む」「動きを見る」、開閉の＋、再生ボタン、タブ、選択して内容を替える部品は講演本文に出さない。
- 元の図と改訂図を観客向けに二重掲載しない。旧版の比較は開発用プレビューかGit履歴で行う。
- JavaScript無効、アニメーション開始前、途中停止、スクリーンショット、印刷でも意味が欠けないHTMLを作る。
- 数値を0から数え上げない。値・単位・前提は完成値で表示する。
- 目次・章へのリンク、アーカイブへ戻るリンク、関連資料リンクは利用可能。隠しコマンドのオーバーレイやQRの閉じる操作も維持する。

## 投影時の情報設計

一つの面に一つの主張を置き、見出しだけでも結論が分かるようにする。章を飛ばして話しても通じるよう、主語・単位・用語の説明をその面に置く。

構造や比較が伝わるときに図を選ぶ。図にしにくい内容は、言葉や数字のパーツで伝える。図を置くために意味のない図を作らない。既存ビルダーの構造検査を無効にする代わりに、必要なら検査とレイアウトを整合させる。

色・書体は [tokens.md](../.claude/skills/ozaken-shiryo/references/tokens.md) に従う。明朝は主張、ゴシックは説明、欧文書体は数字・ラベル。赤は意味のある強調に絞る。意味のない発光で文字のコントラストを下げない。

## 余白の基準

**2026-09-07に本人が確認した、現行テンプレート便覧の余白感を標準とする。** サイクル図（`template.html#figure-cycle`）のように、見出し・図・補足を独立した領域に分け、図の周囲に広い空間を残す。新しく作る資料と改訂する講演資料にも、この間隔と情報密度を引き継ぐ。

- 余白は、図の関係を読み取り、話を聞くための時間をつくる。空いているという理由で文章・カード・装飾を足さない。
- 図を中央に置き、上下左右に呼吸できる空間を取る。小さな構造の図をキャンバスいっぱいに拡大しない。背景の光やグリッドが流れる空間も残す。
- 「見出し→図→補足」の順と領域の区切りを保つ。同じ役割の領域では左右の開始位置を揃え、面ごとに場当たり的な余白を付けない。
- 内容が増えたら、主張を分けて面を増やすか文章を整理する。文字サイズや余白を一律に縮めて詰め込まない。
- 狭い画面では縦に組み替える。背の低い投影画面では下表のコンパクト設定を使い、読める文字と図の周囲の余白を両立する。

基準値は [`template_gallery/lecture.css`](../.claude/skills/ozaken-shiryo/sources/template_gallery/lecture.css) にある。下表の内側余白は「上下 / 左右」。通常画面は幅701px以上・高さ801px以上、コンパクト画面は幅701px以上・高さ800px以下、小画面は幅700px以下。印刷は画面の設定から独立して適用する。

| 領域 | 通常画面 | コンパクト画面 | 小画面 |
|---|---|---|---|
| 各面の見出し領域 | 28px / 38px | 18px / 30px | 23px / 23px |
| 図のキャンバス | 35px / 45px | 20px / 30px | 26px / 20px |
| 図の補足領域 | 20px / 38px | 15px / 30px | 23px / 23px |
| 本文パーツの内容領域 | 45px / 45px | 30px / 30px | 25px / 25px |
| 図版の面と面の間隔 | 50px | 50px | 50px |
| 本文パーツの面と面の間隔 | 45px | 45px | 45px |
| 図のキャンバスの最小高さ | 360px | 300px | 内容に合わせる |

便覧の外枠は最大1380px、図の内容領域は最大1050px。サイクル図自体は最大620pxとし、外側の空間を保つ。画面上の各例は `min-height:calc(100svh - 130px)` を基準に、中央の図の領域へ残りの高さを配分する。これは固定高さではなく、内容が必要とする場合は伸びる。小画面ではこの最小高さを解除する。

印刷では各面の外周を上下12mm・左右15mm、見出し下を5mm、図の上下を6mm、補足上を4mm、本文パーツの上下を8mmとする。画面上の面間隔は取り除き、改ページで区切る。

これらは現在の便覧を再現する基準値。異なる構造の講演資料では、ナビゲーションの有無や用紙サイズに合わせて換算する。便覧の見出し・補足そのものを流用する必要はないが、主張・主役の図や言葉・補足の間隔と情報密度を保つ。標準を変更する場合は実表示で確認し、この節と実装を同じ変更で更新する。

## 表紙とトップページ

トップページは資料一覧への入口であると同時に、講演中にそのまま投影する表紙でもある。ファーストビューの大きなメッセージと余白を保つ。検索や一覧のUIを増やすために表紙を小さくしない。

テンプレート・資料の表紙は、言葉を主役にした抽象的な光のカーテンや面で動かす。右側の固定された説明図を必須にしない。図にできない資料でも同じ表紙を使えることが条件。

表紙のタイトルは短く、署名まで画面に収まるようにする。本文の切り替えを必要としない範囲で、初回の短い導入演出と背景の持続的な動きを組み合わせる。

## 動かしてよいもの

| 対象 | 表現 | 保つもの |
|---|---|---|
| 背景 | ゆっくり移動する青い光、細いグリッド、光の筋 | 本文の位置とコントラスト |
| 図の接続線 | 経路に沿って流れる光点・破線 | 線の全体、矢印、接続先 |
| 強調 | ゆるやかな光・影の変化 | 値、ラベル、選択肢の全情報 |
| 表のホバー | 見出しから最下段まで該当列を同時に強調 | 他の列の内容と読みやすさ |

ホバーで情報を開示・非表示にしない。クリックで選択状態を保存しない。スマートフォンではホバーなしで完結する。印刷にはホバーの強調を残さない。

## 共通の背景実装

共通CSSは [`sources/lecture_effects.css`](../.claude/skills/ozaken-shiryo/sources/lecture_effects.css)。便覧と実装例の両方のビルダーが読み込み、生成HTMLに埋め込む。片方にだけCSSをコピーして保守しない。

```html
<!-- 本文の背後。情報や操作は持たせない -->
<div class="lecture-air" aria-hidden="true"><i></i></div>
```

- 便覧では各 `.tl-canvas` と `.tl-part-example` の中に置く。34図版・33本文パーツの全67例にある。
- 実装例では各章と締めに置く。9章＋締めの10面。表紙は独立した光のカーテンが動く。
- 背景は `z-index:0`、本文は `z-index:1`。親を `position:relative; isolation:isolate` とし、装飾は親の範囲内に収める。
- 本文の背景色で全体の装飾が隠れないよう、各面の内側に置く。ページ背面の固定グラデーションだけで「全章に反映済み」と判断しない。
- `.is-inview`（便覧）または `.dp-inview`（資料）のときだけ再生する。`IntersectionObserver` は大きな面でも動作するよう `threshold:0` を使う。
- タブ非表示と `prefers-reduced-motion: reduce` を扱う。通常は24〜32秒程度の緩やかな背景移動とし、常時の点滅を避ける。
- `@media print` では背景の装飾を隠し、アニメーションとトランジションを止める。

別の講演資料に採用する場合は、その資料のビルダーで同じCSS・HTML・表示状態の管理を組み込む。共通CSSを編集しただけでは、既に生成された暗号化HTMLは変わらない。依頼対象だけを再生成する。

## 配置を壊さないための注意

サイクルのカードと2軸配置図の点は `translate(-50%,-50%)` で座標を中心に合わせている。`[data-motion] { transform:none }` のような一律解除は使わない。表示アニメーションを外す際も、位置決めのtransformは残す。

循環図は上下左右のカードの中心が線上にあり、中心の数字が軌道の中心と一致すること。装飾の動きは別要素・疑似要素に分け、カードの位置決めと混ぜない。

旧スタジオのスマートフォンCSSは `.tl-canvas { order:1 }` を使っている。講演便覧の `.lt-figure .tl-canvas` は `order:0` とし、DOMの「見出し→図→補足」の順を保つ。

## 印刷

便覧と `use-to-delegate.html` の現行講演版はA4横・1面1ページ。本文と図は完成形で印刷し、背景の動き・再生操作・開発用の説明を除く。他の既存PDF出力には16:9の設定もあるため、対象資料の用途に合わせる。

PDFを納品する場合は実際に書き出し、ページ数、改ページ、図とラベル、脚注、空白ページを確認する。CSSの印刷用ルールを画面上で適用した検査は、PDFのページ分割を確認したことにはならない。

## PR・開始・終了の扱い

投影プロフィール（PR）、開始・待機（ST / GO）、終了（EN）は講演の一部。本文の操作UI削除に巻き込まない。動作と対応するハッシュは [運用手順](operations.md#隠しコマンドとプロフィール) を参照。

プロフィールの実績は、数字を派手にするために増やさない。この改修の会話で本人が掲載値として確認した数値は次の通り。集計日は未提示なので、厳密な集計日時を推測で付けない。

| 項目 | 本人確認済みの掲載値 |
|---|---|
| 年間登壇 | 300回超 |
| AI記事 | 1,500本超 |
| Udemy受講者 | 5万人超 |
| AI Agent Day | 累計2万人超 |
| 資格申込 | 1,300人 |

肩書きや実績の対象名は現行プロフィールと本人提供情報を確認して更新する。写真は提供素材の意味に合う場面へ置き、飾りの図へ置き換えない。

## 完了前の確認

1. 通常表示：全情報が最初から読める。開閉・＋・再生・切り替えUIがない。
2. 配置：循環図の中心、線の接続先、表の列、ラベルの収まりを見る。
3. 余白：承認済みの便覧と比べ、図の周囲の空間、領域間の間隔、情報密度を保つ。空間を埋めるための要素を追加していない。
4. 投影と小画面：実測した画面幅を記録し、横はみ出しと読む順番を確認する。
5. 動き：異なる時点の実表示で背景が動くことを確認する。画面外では止まる。
6. 列ホバー：1列だけが全行で強調され、カーソルが離れると戻る。内容は変わらない。
7. 印刷と動きを減らす設定：情報は欠けず、装飾だけが停止・非表示になる。
8. 共通機能：PR / ST / GO / EN / QR、既存リンク、鍵を保持する。

2026-09-07の改修では、通常画面と幅390pxで循環図を確認し、列ホバーの適用・解除、両ページの背景の時間変化、画面外停止を確認。印刷用CSSでは67例と資料の各面で文字のはみ出しなし。実際のPDF出力はこの検証には含めていません。
