# AX記事の強調文レイアウト修正

対象は `01_concept/ax-article.html`。本人添付の画面は本文3面目の強調文。現在の暗号化HTMLを復号し、本文を再生成せず共通デザインの指定だけを更新した。

## 原因と修正

共通本文CSSの `min-height:100svh` と、旧記事CSSの `.statement { max-width:20ch }` が重なっていた。1920px・1422px幅でも文章枠が約497pxに制限され、4行の文章が画面上部に偏っていた。

`sources/lecture_body/body.css` で記事の強調文を本文枠まで広げ、文字を30〜52pxで調整。説明段落 `p.body` を伴わない強調ページだけ縦中央に置く。説明のある9面目は通常の縦の流れを維持する。元の文章・句読点・改行タグ・図・リンクは変えていない。

`scripts/apply_body.py` に `--only` を追加し、この1資料だけ再適用。リポジトリ相対パスを検証し、誤って `index.html` を指定した場合は認証や書き込みの前に終了する。同じ記事用構造の資料を調べた結果、現行の `data-oz-layout="editorial"` はこの1資料だけだった。

## 確認結果

- 実ブラウザで修正後の3面目・9面目と390px幅の強調文を確認。
- 全9章を1920×800・1422×800・390×844の3条件で更新前後比較。27条件すべてで横はみ出し・非表示の本文なし。3面目と9面目以外の本文要素の相対座標・大きさは一致。
- 1920px・1422px幅の3面目は4行から2行に改善。文字領域の中心と面の中心の差は上方205.4pxから上方5pxになった。上下余白85/95pxまたは65/75pxによる5pxの差は標準値を維持。
- 390px幅は文字サイズ30px・4行で全文を表示。最小高さを解除し、内容に応じた高さになる。
- 1010px幅で印刷CSSを適用した3面目・9面目を検査し、本文の非表示・横はみ出しなし。実PDFの書き出し・改ページ検証は今回行っていない。
- 背景は既存の装飾レイヤーを保持。通常表示で再生状態と変形が適用され、印刷用表示では装飾が消えることを確認。
- `apply_body.strip()` 後の全文が更新前とバイト単位で一致。内容ハッシュは `1e99fe30c57ff43231ce25bde8609dafaedf4c424c5c6da64fdae97022600c0b`。再適用の冪等性・暗号化後の復号一致・ラップ鍵W・既存注入ブロックの保持を確認。
- 共通表紙・本文の既存ユニットテスト12件とPython構文検査を通過。
