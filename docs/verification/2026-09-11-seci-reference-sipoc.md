# 本人提供図によるAI-SECI改訂とSIPOCの具体化

2026-09-11の追加依頼を反映。対象はAI-SECI、5レベルのCopilot編・Gemini編、業務分解大全の4資料。基準コミットは `058eecf`。トップ・テンプレート・他の資料は対象外。

## 変更内容

AI-SECIは本人提供の4象限図を基準に、S・E・C・Iを時計回りで表した。共同化は暗黙知の自己認識と他者との共有、表出化はプロンプトやワークフローへの変換、結合化は仕組みの連携、内面化は現場で使う人の暗黙知の更新として、各工程を独立した章で説明する。システムプロンプトの重要性、コンテキストエンジニアリング、RAG・MCP、現場レビューも図と解説に含めた。本人の応用と原典への参照を区別した。

5レベルはAI-SECIに接続する1章だけを同じ定義へ更新。L2・L3の作成手順を含む他の17章は、両版ともバイト単位で一致する。

業務分解大全はMethods章の直後へ次の4章を追加した。

1. 週次の定例会議資料の作成を使ったSIPOCの記入例
2. 業務名 → P → O・C → S・Iの記入順とプロセス5つ前後への分解
3. 繰り返し・入出力・最後の人の確認という3つだけの判断基準
4. ①抽出・②集計・④資料化＝◎、③コメント収集＝○、⑤マネージャー確認＝×の判定例

元の10章のうち9章は完全一致する。残るWorksheet 1も、導入の記入順だけを新しい説明へ合わせ、元の請求書処理の図・例・他の本文を保持した。既存の内容を独自の判定で書き換えていない。
