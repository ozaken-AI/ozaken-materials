# 情報源と、拾う／捨てる基準

## カテゴリ（この3つに固定する。増やさない）

1. **生成AI** — 基盤モデル、提供形態、価格、計算資源、規制
2. **AIエージェント** — エージェント基盤・運用製品、自律実行、業務組み込み
3. **フィジカルAI** — ロボット基盤モデル、ヒューマノイド、産業ロボ、関連政策・市場

どれにも入らないものは載せない。無理に3分類へ押し込まない。

---

## 収集のやり方

`WebSearch` で、対象期間を明示した検索を **最低6本** 投げる。日本語・英語の両方を必ず混ぜる。

推奨クエリの型（`{期間}` は「2026年7月27日 8月2日」のように具体的な日付で）：

- `生成AI ニュース {期間} 発表`
- `AIエージェント {期間} 企業向け 発表`
- `フィジカルAI ロボット基盤モデル {期間}`
- `OpenAI Anthropic Google AI announcement {期間 in English}`
- `AI agent platform enterprise launch {期間 in English}`
- `humanoid robot foundation model {期間 in English}`
- （必要に応じて）`AI 規制 ガイドライン {期間}` / `AI API 価格 改定 {期間}`

各社の一次情報が取れるなら `WebFetch` で裏を取る。**アグリゲータ記事しか取れなかった項目は、その旨をダイジェストに残す**（後から出典の強さを判断できるようにするため）。

### 参考になる情報源

一次情報（可能なら必ずこちらを出典にする）
- OpenAI / Anthropic / Google DeepMind / Google Cloud / Microsoft / Meta AI / xAI / NVIDIA の公式ブログ・ニュースルーム
- 経済産業省・総務省・デジタル庁の報道発表
- 各社の料金ページ（価格を扱うときは必ず現物を見る）

二次情報（拾い漏れを潰す用。出典として使う場合は日付と原典を確認する）
- TECH NOISY、gais.jp、eguweb、ロボスタ、PR TIMES のAI関連
- 海外テックメディア（TechCrunch / The Verge / VentureBeat 等）

## 載せる基準（3つ全部を満たすものだけ）

1. **その週に実際に動きがあったか** — 「発表予定」「観測記事」は載せない
2. **日本の組織の意思決定に効くか** — 研究成果そのものより、使える形になったかを見る
3. **3か月後に読み返して意味が残るか** — ベンチマークの小数点更新、細かなUI変更は捨てる

### 捨てるもの（判断に迷ったら捨てる）

- ベンチマークスコアのマイナー更新
- 資金調達のうち、製品・提供形態が変わらないもの
- 「〜が話題」「〜が物議」だけの記事
- 個人の考察・ポエム記事
- 同一ニュースの後追い記事（一次に寄せて1件にまとめる）

### 週あたりの件数

**カテゴリごとに最大4件、週あたり合計12件まで。** 足りない週は無理に埋めない。
「今週のフィジカルAIは特筆なし」と書くほうが、水増しより価値がある。

---

## 各項目に必ず持たせる情報

- 日付（YYYY-MM-DD。期間なら範囲）
- 見出し（事実だけ。煽らない）
- 出典URL（一次情報を優先。二次なら `※二次情報` と付す）
- **意味づけ 1〜2文** — 「で、何が変わるのか」。ここがおざけんの資料の価値なので、事実の言い換えで済ませない
- 関連する既存資料（`references/material-map.md` で引く。無ければ「なし」）
