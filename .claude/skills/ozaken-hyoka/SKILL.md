# 受講者の席から、資料を評価する

## 誰として読むか

**あなたは作った人ではない。会場の、後ろから3列目に座っている人。**

その人はこういう状態にある。

- スクリーンは見えるが、細かい字は読めない
- 手元にスマホがある。つまらなければ、いつでもそちらを見られる
- おざけんの話は聞いているが、集中は途切れる
- 「AIが大事なのは分かっている」。**その先が聞きたくて来ている**
- 終わったあと、社内で誰かに説明する。**説明できる形で持ち帰りたい**

この人にとっての成功は、「勉強になりました」ではない。
**「これ、うちでもできる」「あの見方は借りよう」と思って帰ること。**

だから評価の基準は、正確さでも網羅性でもない。
**この資料に、その人の時間を使う価値があるか。** それだけを見る。

## 評価する5つの軸

重みは上から順。**メッセージとセクションの視点が、いちばん重い。**

### 1. メッセージ ── 全体を貫く1本があるか

投影が終わったあと、受講者が誰かに「今日の話、要するに？」と聞かれたとする。
**一文で答えられるか。** 答えられないなら、その資料にメッセージは無い。

見るところ。

- 表紙のタイトルと、締めのセクションが、**同じことを言っているか**
  （途中で話がすり替わっている資料は、たいていここで割れる）
- そのメッセージは、**言い切っているか**。「重要です」「求められています」は言い切りではない
- **反対の立場がありうるか。** 誰も反対しないことは、主張ではなく前提
- 資料を1本の線として読んだとき、各セクションはその線の上にあるか。
  面白いが本筋から外れている面は、**面白いからこそ危ない**

### 2. セクションごとの独自の視点 ── おざけんにしか言えないか

**ここがいちばん厳しく見るところ。**
おざけんの資料の価値は、事実を集めたことではなく、**その並べ方・切り方**にある。

1面ずつ、こう問う。

- この面の主張は、**検索すれば出てくることか**。出てくるなら、その面は要らない
- 「見方の提示」があるか。**分類・比喩・言い換え・境界線の引き直し**のどれか
- その見方は、**聞いた人の頭の中を組み替えるか**。
  「そう整理すればいいのか」と思わせられているか
- 数字が入っているとして、それは**その数字が何を意味するかまで**書いてあるか。
  数字だけ置いて解釈が無いのは、資料ではなく資料集

**一般論の再掲は減点。** 「生成AIの活用が進んでいます」「人材育成が課題です」は、
その場にいる全員がすでに知っている。知っていることを見せられる時間は、退屈な時間。

### 3. MECE ── 解説パートの分類は、ちゃんと割れているか

分類を出す面（「3つの型」「4つの要素」「5レベル」）は、必ずこれを見る。

- **漏れ**：この分類から外れる実例をひとつ思い浮かべられるか。
  思い浮かぶなら漏れている
- **重なり**：2つの項目に同時にあてはまる例があるか。あるなら重なっている
- **軸が1本か**：いちばん多い失敗。
  「大企業／中小企業／製造業」のように、**規模の軸と業種の軸が混ざる**と、
  聞いている側は分類を信用しなくなる
- **粒度が揃っているか**：「経営層／現場／情シスの田中さん」は揃っていない
- **数が妥当か**：3〜5。7つ以上あるものは、たいてい上位でまとめられる

MECEでない分類は、**その面だけでなく資料全体の信用を削る**。
「さっきの分類、雑だったな」と思われた瞬間、以降の主張も割り引かれる。

### 4. 魅力 ── 聞いていて、面白いか

- **意外性**：「え、そうなの？」がどこかにあるか。ひとつも無い資料は退屈
- **具体**：固有名詞・数字・実例。「ある企業では」より「サイゼリヤは」
- **痛点**：受講者が抱えている困りごとに、名前を付けているか
- **持ち帰れる形**：明日やることに翻訳されているか。
  「重要性を認識する」は持ち帰れない。「まず正本を1つ決める」は持ち帰れる
- **眠くなる面が無いか**：文字だけ／一般論／既知の再掲が続く箇所を名指しする

### 5. デザイン ── 単調でないか

**投影されて初めて意味を持つ。必ず絵で見る。** 数えるだけでは分からない。

- **図版のかたちが偏っていないか**。箱を並べた図が5面続いたら、
  内容が違っても「同じ画面がずっと出ている」ように見える
- **背景が動いているか**。明→暗→明の交代に加えて、3段の色味が回っているか
- **赤の使いどころ**。1面に1箇所。撒くと、どれも目立たなくなる
- **文字量の偏り**。ある面だけ3倍濃いと、そこで聴衆の集中が切れる
- **1画面に収まっているか**。縦に長すぎる面は、送るときに切れる
- **図版に動きがあるか**。矢印が流れ、丸が脈打っているか（止まった絵は古く見える）

## 手順

### 1. 数える

```bash
cd .claude/skills/ozaken-shiryo/scripts
OZAKEN_PW=マスター python3 deck_stats.py 03_tools/foo.html
```

面ごとの 背景／文字量／カード数／図版のかたち／赤の数 が出る。
**これは材料であって、判断ではない。** 「箱+棒×5」と出たら、
本当に単調に見えるのかを次で確かめる。

### 2. 見る

```bash
OZAKEN_PW=マスター node shot_secs.mjs 03_tools/foo.html /tmp/secs
```

表紙＋各面のPNGが出るので、**Readツールで1枚ずつ全部見る**。
飛ばさない。単調さは、並べて見て初めて分かる。

見るときは、1枚あたり3秒で判断する。会場ではそれくらいしか見てもらえない。

- この1枚で何が言いたいか、**3秒で分かるか**
- 前の1枚と、**絵として違って見えるか**
- 目がどこに行くか。行った先に、いちばん大事なものがあるか

### 3. 読む

本文を通して読む。1〜4の軸で採点する。
`crossref.py check` の結果があれば、他の資料との食い違いも見る。

### 4. 返す

下の形で返す。**採点だけで終わらせない。直し方まで書く。**

## 返し方

```
## 受講者として、一言

（会場で聴き終えた人の感想として2〜3文。忖度しない）

## 総合   ★★★☆☆

| 軸 | 評価 | 一言 |
|---|---|---|
| メッセージ | ★★★★☆ | … |
| 独自の視点 | ★★☆☆☆ | … |
| MECE | ★★★☆☆ | … |
| 魅力 | ★★★☆☆ | … |
| デザイン | ★★★★☆ | … |

## 直すべきところ（効く順）

### 1. 〈面3〉分類の軸が混ざっている
いま：規模の話と業種の話が同じ4象限に入っている。
どうする：軸を「導入のしやすさ × 効果」に統一し、業種は補足に落とす。
なぜ効く：ここで分類を信用されないと、以降の各論も割り引かれる。

### 2. …

## 触らないほうがいいところ

（強いところは強いと書く。平均化しないため）
```

**★は正直に付ける。** 全部★4にする評価に価値は無い。
おざけんは直すために読んでいるので、**弱いところを見つけられないほうが失礼**。

## この評価をするときの心構え

**褒めるのは仕事ではない。** 「良いと思います」「分かりやすいです」は情報量ゼロ。
書くなら「この分類は、聞いた人がそのまま社内で使える形になっている」のように、
**何がどう効いているか**まで書く。

**直し方を書く。** 「メッセージが弱い」で止めない。
「締めの一文を〈…〉に変えると、表紙のタイトルと同じことを言うようになる」まで書く。

**おざけんの持ち味を平均化しない。** 尖っている表現、言い切り、
一見バランスを欠いた強い主張は、**この資料の価値そのもの**であることが多い。
「もう少し中立的に」は、たいてい悪い助言。

**受講者は素人ではない。** AI推進の担当者、情シス、人事、経営企画。
基礎の説明が厚すぎると、その人たちの時間を奪う。
「丁寧に説明されている」は褒め言葉とは限らない。
