# 面ごとに当てる問い

急いでいるときは、これだけでもいい。
**1面ずつ、順に当てる。** 全体をぼんやり眺めても、弱いところは見つからない。

## この面を見て、3秒で

- [ ] 見出しだけで、この面の主張が分かる
- [ ] 目が最初に行く場所に、いちばん大事なものがある
- [ ] 前の面と、**絵として**違って見える
- [ ] 文字の壁になっていない（図が無い面は、それだけで赤信号）

## 中身

- [ ] この面の主張は、**検索して出てくること**ではない
- [ ] 「見方」が提示されている（分類・比喩・言い換え・境界線の引き直し）
- [ ] 数字があるなら、**その数字が何を意味するか**まで書いてある
- [ ] 具体（固有名詞・実例）がある。「ある企業では」で逃げていない
- [ ] この面が無くても資料が成立するなら、**なぜ置いてあるか**を説明できる

## 分類を出している面なら

- [ ] この分類から外れる実例を、思い浮かべられない（＝漏れが無い）
- [ ] 2つの項目に同時にあてはまる例が無い（＝重なりが無い）
- [ ] 軸が1本（規模と業種、時間と主体が混ざっていない）
- [ ] 粒度が揃っている
- [ ] 3〜5個。7個以上なら、上位でまとめられないか

## 全体を通して

- [ ] 「今日の話、要するに？」に**一文で**答えられる
- [ ] 表紙のタイトルと、締めの一文が、同じことを言っている
- [ ] そのメッセージには、**反対の立場がありうる**（誰も反対しないなら主張ではない）
- [ ] 明日やることに翻訳されている面が、少なくとも1つある
- [ ] 「え、そうなの？」が、少なくとも1つある
- [ ] 同じかたちの図が3面以上続いていない
- [ ] 赤は1面に1箇所まで
- [ ] 文字量が、最も薄い面と最も濃い面で3倍以内

## 赤信号（見つけたら必ず書く）

- 一般論だけの面（「重要性が増しています」「課題となっています」）
- 分類の軸が混ざっている面
- 数字を置いただけで、解釈が無い面
- 図が無い面
- 締めが、本文の要約になっている面（締めは要約ではなく、視点の引き上げ）
- 表紙のタイトルと締めが、別のことを言っている
