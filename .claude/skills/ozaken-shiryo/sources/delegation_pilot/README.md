# 「使うAI」から「任せるAI」へ — デザイン試作

対象は `01_concept/use-to-delegate.html` の1本。表紙・9章・締めを、講演で投影する画面として構成する。

- 右側は抽象的な光のカーテン。資料の内容を図式化できるかどうかに依存しない。
- 各章は短い主張と大きな図。比較・境界・層・業務分解・差し戻しなど、意味のある状態変化を使う。
- 元の18図・27カード・関連資料リンクは、章ごとの解説に残す。
- 図の初回再生は有限。手動切り替え、再生、全体の停止に対応。背景は表示中だけ動く。
- 小画面では縦組み。参考図は細字に縮小せず横にスクロールする。
- 文字キーは既存の `apply_keynav` に任せる。QRは既存ページのブロックを保持する。

## 生成

このディレクトリで実行する。`--output` はGit管理外のローカルプレビュー先にする。

```sh
python3 build.py --output /absolute/local-preview/01_concept/use-to-delegate.html
```

既存QR・関連リンクを含める場合は `--preserve`、暗号化された対象HTMLを書き戻す場合は `--update` を付ける。マスターは対話入力で受け取り、ファイルには保存しない。既存のラップ鍵を変えずに再暗号化し、復号結果との一致を確認する。

`--baseline` は、既存ブロックを元の暗号化HTMLから復元する場合だけ指定する。通常の再生成には不要。

内容は `../gen_use_to_delegate.py`、試作の構成は `build.py`、見た目は `pilot.css`、操作は `pilot.js` に分ける。共通 `publish.compose()` の検査と組み立てを通した後、この資料の装飾だけを置き換える。一括再適用や台帳更新は行わない。

## 確認

1280×720、1440×900で全11面の投影用表示を確認。390px、320pxではページの横はみ出しがなく、操作と読める文字を優先して縦に伸ばす。解説を開いたときは意図的に長くなる。

講演会場での投影やOSの視差効果設定の実機切り替えは、ブラウザーでの確認とは別途必要。`prefers-reduced-motion` に対するCSS/JSの分岐を実装している。

試作のブランチであり、本番への公開は別の操作。
