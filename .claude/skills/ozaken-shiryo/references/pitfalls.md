# ハマりどころ

実際に踏んだものだけを載せている。読んでおくと、同じ穴に落ちずに済む。

## 図版

### `<b>` や `<br>` がそのまま文字として出る
SVGの中では使えない。`lines()` も `esc()` も、タグを実体参照に変える。
**強調したいときは色を変えるか、行を分ける。**
HTML本文（カードの中）では `<b>` を使ってよい。

### 英単語が途中で切れる
`wrap()` は英数字の連なりを途中で切らないようにしてあるが、
極端に幅が狭いと戻しきれない。`BluStellar` が `BluSt` / `ellar` になったことがある。
**列を広げるか、文字数上限を守る。**

### 同じページに同じ図版を2つ置くと矢印が消える
`fig_gap` `fig_issues` `fig_flow` `fig_cycle` `fig_tree` は SVG の `marker` を使う。
id が衝突すると、後から描いたほうの矢印が壊れる。
**`uid` に必ず違う文字列を渡す。** `check()` が重複を弾く。

### 回転させたテキストに矢印記号を入れると弾かれる
`fig_quad` `fig_map` の y軸ラベル。`↑` を入れると向きが破綻するので、
`check()` が落とす。「効果の大きさ ↑」ではなく「効果の大きさ」と書く。

### 文字が箱からはみ出す
いちばん多い。**SVGは折り返さない。** `references/figures.md` の文字数上限を守る。
そのうえで**必ずレンダリングして目で見る**。コードは通るし、ブラウザもエラーを出さない。

### 汎用の図に、意味の合わないラベルが残る
`fig_issues` は「壁 1」「壁 2」、`fig_gap` は「いま」「3年後の到達像」を
既定で持っている。手順を描くのに `fig_issues` を使うと「壁1: 棚卸し」になる。
**形が似ているからと流用しない。** `fig_flow` を使うか、新しい関数を足す。

## 暗号化

### `lockbox.encrypt` の引数順
`encrypt(path, pw, plaintext)`。`(path, plaintext, pw)` と書いて
「パスワードが違います」で悩んだことがある。

### `create` と `encrypt` の使い分け
- `encrypt(path, pw, html)` … **本文だけ差し替える。鍵はすべて維持される**
- `create(tpl, html, out, [pw...])` … **鍵を作り直す。既存のパスワードは無効になる**

既存資料の中身を直すときに `create` を使うと、配布済みのパスワードが死ぬ。
**直すだけなら必ず `encrypt`。**

### 暗号化ページに演出を当て直すとき
`apply_*.py` は「印がすでにあれば何もしない」ので、CSSを直しても反映されない。
`reapply.py <対象>` を使う。古い版を剥がしてから入れ直す。

## 構成

### セクションを1本足すと `check()` が落ちる
本文セクションは**奇数本**でなければならず、light/navy が交互で、
最後は navy。1本足すと偶数になる。**足すなら2本、または既存を統合する。**

### 節を足しても背景の割り当ては崩れない
`data-bg` 属性で持たせているので、あとから挿入しても問題ない。
`apply_bgcycle.py` を当て直せば振り直される。

## 素材

### 会話に添付された画像は、こちらからディスクに保存できない
資料に画像を使うときは、**ユーザーにリポジトリへコミットしてもらう**。
`99_assets/` に置いてもらい、そのパスを参照する。

### PDFの表は画像で埋め込まれていることが多い
`pypdf` のテキスト抽出では数値が落ちる。
`pymupdf` でページをPNGにして、Readツールで目で読む。

```python
import fitz
fitz.open(path)[6].get_pixmap(dpi=170).save('/tmp/p7.png')
```

### Googleのドメインに接続できないことがある
この環境ではプロキシで遮断されている。
公式の料金ページが読めないときは、**二次情報＋確認日を明記**する。
「2026年8月時点／二次情報にもとづく」と書けば、壇上で補足できる。

## 検証

### `elementHandle.hover()` がタイムアウトする
ファーストビューの要素はアニメーションで動き続けているため、
Playwright が「安定していない」と判断して待ち続ける。
`page.mouse.move()` に `boundingBox()` の座標を渡す。

### `getComputedTextLength()` は当てにならない
`lines()` が生成する `<text>` は `<tspan>` を複数持つので、
返る値は全行の合計になる。**はみ出し検出には使えない。** 目で見る。

### レンダリング前に `data-reveal` を外す
本文は画面に入るまで透明。スクリーンショットを撮る前に、
`document.querySelectorAll('[data-reveal]').forEach(e => e.classList.add('visible'))`
で可視化する。`shot_figs.mjs` はこれをやっている。
