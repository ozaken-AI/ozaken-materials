# 取引先の正式名称

**資料・提案書・請求書に社名を書く前に、ここを見る。**

前株か後株かは、相手にとって自社の名前そのものだ。間違えると、
中身をどれだけ作り込んでも「うちのことを分かっていない」という印象が先に立つ。
一度指摘されたものは、必ずここに書き足す。

| 正式名称 | 誤りやすい形 | 備考 |
|---|---|---|
| 株式会社フジシールインターナショナル | ~~フジシールインターナショナル株式会社~~ | **前株**。2026年8月、先方よりご指摘 |
| カナデビア株式会社 | ─ | 後株 |
| 三井住友海上あいおい生命保険株式会社 | ─ | 後株 |
| Fintegrity株式会社 | ~~株式会社Fintegrity~~ | **後株。社名は英字のまま**。2026年8月、先方の案内状で確認（代表取締役 三木佑也 様／香川県高松市） |

## 書き方の決まり

- **初出は正式名称をそのまま書く。**「（株）」への略記はしない。
- 2回目以降は「フジシール様」のように略してよいが、
  **表紙・扉・奥付・請求書は必ず正式名称**にする。
- 個人名に敬称を付けるときは「様」。資料の中で社名に「様」は付けない
  （「株式会社フジシールインターナショナル 御中」か、社名のみ）。
- 資料の中で相手先を名指しするのは、表紙と、その資料が相手のために
  作られたことを示す1か所だけでよい。各節に社名を散らすと、
  使い回しの効かない資料になる。

## 新しい取引先を足すとき

提案・見積・登壇のどれであっても、**最初に登記上の正式名称を確認して、
ここに1行足してから資料を作る。** 確認先は、先方のコーポレートサイトの
会社概要か、国税庁の法人番号公表サイト。名刺の表記は略されていることがある。
