# 本番での使い方

資料は作って終わりではない。**壇上で操作されて、はじめて役に立つ。**
ここを知らないと、せっかくの仕掛けが使われないまま終わる。

## ショートカット

index.html でも、どの資料の上でも、**2文字打つと発動する**。
資料ページで打った場合は index の該当画面へ飛ぶ。

| キー | 出るもの | 使う場面 |
|---|---|---|
| `go` | 起動アニメーション | 開演直前。掴みとして |
| `st` | 開演前の待機画面（QR付き） | 開場中、席に着く人が資料を取れる |
| `ti` | タイトルカード（その場で入力できる） | セッションの頭出し。会場名や日付を打ち込める |
| `pr` | プロフィール（スクロール型） | 自己紹介。長く話すときはこれを流す |
| `qa` | 質問箱のQRと、届いた質問のタイムライン | 講演中ずっと出しておける |
| `ma` | 資料アーカイブの星座マップ | 「こういう資料があります」と見せるとき |
| `th` | お礼＋資料アーカイブのQR | 締め |
| `en` | 終了演出 → お礼画面 | 締めを演出込みでやるとき |
| `ur` | 裏資料置き場の解錠 | スポット講演・パネル用 |
| `pw` | パスワード台帳の解錠 | 個別パスワードを確認したいとき |
| `mx` | 資料マトリクス（資料×概念の一覧） | 「この話は、この資料でしています」と示すとき |

`Esc` でどの画面も閉じる。画面をクリックすると全画面表示に切り替わる。

## 動かし方

**決まった順番はない。** おざけんは会場の反応を見て、その場で出すものを選ぶ。
だから覚えておくべきなのは「どのキーで何が出るか」だけで、段取りではない。

ひとつだけ、実務的なこと。**質問箱を使う日は、開演の数分前に一度 `qa` を開いておく。**
Apps Script は久しぶりに呼ばれると起動に数秒かかる。
先に温めておけば、本番での更新は即座に返る。

## 質問箱

聴講者は `ask.html` に飛んで、**名前と質問だけ**を送る。
届いたものは投影ページのタイムラインに並び、`ask.html` の下部にも出るので、
後ろの席やオンライン参加でも読める。

- 既定では**直近3時間**だけを表示する。前の講演の質問が混ざらないため
- 見出しの範囲表示を押すと 直近1時間／3時間／今日／すべて を切り替えられる
- 出したくない質問が来たら、スプレッドシートの `questions` シートの **H列に×を打つ**。
  次の更新で消える
- 講演ごとに分けたいときは、QRのURLに `?s=講演名` を付ける。
  「聞いた場」列に自動で記録される

## 資料の渡し方

3本の鍵がある。**渡す相手で使い分ける。**

| 鍵 | 渡す相手 |
|---|---|
| マスター | 誰にも渡さない |
| 共通（`O29daisuki`） | まとめて何本も渡すとき |
| 個別（`otter-lily-turtle` 形式） | 特定の資料を、特定の相手に渡すとき |

個別パスワードは**passwords.html**（`pw` で開く）に載っている。
共有先も記録できるので、「誰にどれを渡したか」が後から追える。

```bash
OZAKEN_PW=マスター python3 .claude/skills/ozaken-shiryo/scripts/registry.py set \
    05_drive/kiban-phase.html 合言葉 --to "みずほFG 8/6"
```

台帳だけは共通パスワードで開かない。全資料の鍵が載っているため。
