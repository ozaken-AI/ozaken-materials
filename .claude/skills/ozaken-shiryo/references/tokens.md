# 色とフォントの規定

投影資料の見た目が資料ごとにバラつく最大の原因は、**その場の思いつきで色とフォントを足すこと**。
ここに載っていない色・書体は使わない。足したくなったら、まずこの表を疑う。

`build_page.check()` が機械的に見ているので、規定外の色を入れると公開できない。

## 色

### 地の色（背景）

| トークン | 値 | 使う場所 |
|---|---|---|
| `--paper` | `#f8f7f4` | 明るい面の地。いちばん基本 |
| `--navy` | `#1f3864` | 暗い面の地 |
| `--navy-deep` | `#141d35` | いちばん深い地。締めの面 |
| `--white` | `#ffffff` | 図版のカード、表の地 |

面ごとの循環用に、これらから派生した6色を `apply_bgcycle.py` が持っている
（`#eef3fa` `#e7eef8` `#f6f2ea` `#f1eade` `#24446f` `#182c55` `#182a52` `#131c33`）。
**これは自動で割り当てられるので、自分で背景色を書かない。**

### 文字の色

| トークン | 値 | 使う場所 |
|---|---|---|
| `--ink` | `#1a1a2e` | 明るい面の本文・見出し |
| `--white` | `#ffffff` | 暗い面の本文・見出し |
| `--muted` | `#6b7a99` | 明るい面の補助文字、図版のキャプション |
| `--azure-pale` | `#d8e4f0` | 暗い面の補助文字 |

暗い面での補助文字は `rgba(255,255,255,.6〜.72)` も可。
**明るい面の補助文字に、白の透過は使わない**（投影で消える）。

### 意味を持つ色

ここが最も大事。**色は装飾ではなく意味の担い手**として使う。

| トークン | 値 | 意味 |
|---|---|---|
| `--azure` | `#2e5496` | 主色。図版の基準線、eyebrow、リンク、01番目の要素 |
| `--red` | `#e23744` | **危険・禁止・NG・ここが要点**。明るい面で使う |
| `--red-bright` | `#ff5d6a` | 同上。暗い面で使う |
| AMBER | `#c9762f` | 注意・中間・02番目。危険ではないが目を引かせたいもの |
| TEAL | `#2f8f8a` | 別系統・03番目。青とも赤とも違うことを示す |

**赤は1画面に1箇所まで。** 赤が2つ以上あると、どちらが要点か分からなくなる。
「なんとなく目立たせたい」で赤を使わない。目立たせたいだけならAMBERを使う。

図版で3系統以上を色分けするときは `ACCENTS = [AZURE, RED, AMBER, TEAL]` の順で使う。
差し色のindexは、この配列の並び。

### 補助的に使う色

| 値 | 使う場所 |
|---|---|
| `#9fc6f5` | ファーストビューの演出（走査線・枠・星座線）。本文では使わない |
| `#46c98a` | 「稼働中」を示す緑の点だけ。それ以外に緑を使わない |
| `#eef1f6` | 図版の中の、沈ませたい箱（`fig_gap` の左側など） |
| `#fde8ea` / `#fff8f8` | NG判定の帯・地（`.jd` の禁止側） |

### 使ってはいけないもの

- 上の表にない色（紫・ピンク・黄緑・水色など）
- 純黒 `#000000` と純白以外のグレー。沈ませたいときは `--muted` か `#eef1f6`
- グラデーションの自作。背景のグラデーションは `apply_bgcycle.py` の管轄

## フォント

3書体だけ。それ以外を読み込まない。

| 変数 | 書体 | 使う場所 | ウェイト |
|---|---|---|---|
| `--font-ja-serif` | Shippori Mincho B1 | 大見出し（`hero-title` `sec-title` `thanks-title`）、`lede`、`kicker` | 500 / 600 |
| `--font-ja-sans` | Zen Kaku Gothic New | 本文、カード、**SVG図版の中のすべての文字** | 400 / 500 / 700 |
| `--font-en` | Hanken Grotesk | 英数字のラベル、数値、`eyebrow`、`card-tag`、システム表記 | 600 / 700 |

### 守ること

- **SVGの中は必ず `--font-ja-sans`**。明朝は線が細く、投影すると飛ぶ。
  `domain_fig.py` はまとめて指定しているので、個別に書き換えない
- **英数字の見出しに `--font-en` を使うときは `letter-spacing` を必ず付ける**（0.12〜0.42em）。
  詰まった英字は投影で読みにくい
- **数値には `font-variant-numeric: tabular-nums`**。桁が揃って比較しやすくなる
- サイズは `clamp()` で書く。投影と手元の両方で成立させるため。
  本文は最小でも16px相当を下回らない
- `font-weight` は上の表の値だけ。300や900のような極端なウェイトは、
  可変フォントとして読み込んでいないので、ブラウザが勝手に太らせて汚くなる

### 書体の役割分担

明朝（Shippori Mincho）は**主張**、ゴシック（Zen Kaku）は**説明**、
英字（Hanken Grotesk）は**ラベルと数値**。

この分担が崩れると、どこを読めばいいのか分からない画面になる。
「見出しをゴシックにしたい」と思ったときは、たいてい見出しが長すぎる。
書体を変えるのではなく、見出しを短くする。
