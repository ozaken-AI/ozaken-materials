# ozaken-materials

小澤健祐（おざけん）のAI関連解説資料アーカイブ。トップページは [`index.html`](./index.html)（GitHub Pages 公開中: https://ozaken-ai.github.io/ozaken-materials/ ）。

資料は「AIを組織で使えるようにするまでの問いの連鎖」を軸に、**知る → 選ぶ → 動かす** の流れでMECEに分類しています。

## フォルダ構成

| フォルダ | 答える問い | 内容 |
|---------|-----------|------|
| `01_概念・思想/` | AIをどう捉えるか（Why/What） | AXとは、AIエージェント実装の5レベル、Human in/on the loop、パーパス論 |
| `02_技術・モデル動向/` | いまAIは何ができるか | モデル使い分け、モデル分業16の型、AI音声、Google I/O、Mythos |
| `03_ツール・製品/` | 何を使うか | ChatGPT Work、Cowork |
| `04_活用・実践/` | 現場でどう使いこなすか | プロンプトエンジニアリング、AIで資料作成 |
| `05_推進/` | 組織にどう広げ、根付かせるか | AI推進51施策・大全、資格制度（ストラテジスト）、予算 |
| `06_キャリア・人材/` | 働き方と人材はどう変わるか | AIエージェント時代のキャリア、OpenAI FDE、人事 |
| `07_リスク・法務/` | どう守るか | 個人情報保護法 |
| `10_ニュース/` | いま何が動いているか | 週次のAIニュースダイジェスト、月次トレンド（→ [運用](./10_ニュース/README.md)） |
| `99_assets/` | （コンテンツでない素材） | 登壇スライド、画像素材 |

## AIニュースの週次・月次まとめ

生成AI・AIエージェント・フィジカルAIのニュースを、週に1回集めて月に1回束ね直す仕組みを入れています。

- 最新月のトレンドは `index.html` の「今月のAIトレンド」に表示され、それ以前は [`10_ニュース/トレンドアーカイブ.html`](./10_ニュース/トレンドアーカイブ.html) に積み上がります
- 既存資料への反映は**必ずプルリクエストで提案し、承認された分だけ**適用します（自動で本文が書き換わることはありません）
- 詳細は [`10_ニュース/README.md`](./10_ニュース/README.md)

## 更新方法

ファイルを追加・修正して以下を実行すると、数分後に GitHub Pages に反映されます。

```bash
git add .
git commit -m "資料を更新"
git push origin main
```
